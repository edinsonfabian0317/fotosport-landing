PUBLICACIÓN GRATUITA EN GITHUB PAGES
1. Descomprime fotosport-landing-page.zip.
2. Entra a https://github.com y crea un repositorio público, por ejemplo: fotosport-landing.
3. Sube al repositorio todos los archivos y carpetas del contenido descomprimido (index.html debe quedar en la raíz).
4. En Settings > Pages, selecciona Deploy from a branch, elige la rama main y la carpeta / (root), y guarda.
5. GitHub mostrará la URL gratuita de publicación, normalmente https://TU-USUARIO.github.io/fotosport-landing/.
